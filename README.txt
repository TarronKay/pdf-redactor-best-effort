PDF REDACTOR BEST EFFORT 0.9.2 - UNSIGNED EVALUATION

Windows 10/11 x64, local/offline processing. Open a PDF, review suggestions,
add/remove boxes, export a new copy, then inspect every page and searchable text.
Checking pages is optional. Best-effort selectable text can retain hidden,
white, occluded, misplaced and unselected identifying text. Image-only output
omits searchable text but still needs complete visible selection.
Export does not prove anonymity. No warranty; no NBME affiliation/endorsement.

This public release supports Best Effort raster and text only. It does not
include legacy strict hybrid or native reconstruction. No source PDF objects
are copied into exports. Original files are preserved; numbered PDF/JSON pairs
are saved. Inputs are limited to 20 MiB and 1-30 pages.
